# My First Portfolio Website

The first portfolio website I built when I started learning web development, using only HTML and CSS.

## Pages and sections

- **Home** (`index.html`): About me, my interests and my projects (including an Amazon e-commerce clone)
- **Contact** (`contact.html`)

## Tech Stack

- HTML5
- CSS3
- Google Fonts (Young Serif)

## Run locally

No build step is needed.

```bash
git clone https://github.com/BALASUBRAMANIYAN-S/First_Portfolio_Website_Starting_Of_WebDevepment.git
cd First_Portfolio_Website_Starting_Of_WebDevepment
```

Open `index.html` in a browser.

## Deployment

A GitHub Actions workflow (`.github/workflows/static.yml`) deploys the site to **GitHub Pages** on every push to `main`. To enable it, go to the repo's **Settings → Pages** and set the source to **GitHub Actions**.

## Project Structure

